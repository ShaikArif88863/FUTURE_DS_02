Task 2: Customer Retention & Churn Analysis

Project Overview

This project analyzes customer and subscription data to understand why customers leave a service and identify ways to improve customer retention.

The goal is to discover churn patterns, compare customer segments, study customer tenure, and provide data-driven recommendations for a subscription-based business.

Objectives

- Clean and prepare the customer dataset.
- Calculate the customer churn rate.
- Analyze retention trends and customer tenure.
- Compare churn across contract types and customer segments.
- Identify factors associated with customer churn.
- Recommend strategies to improve customer retention.

Tools and Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- GitHub

Planned Analysis

1. Data cleaning and preparation
2. Exploratory data analysis (EDA)
3. Churn rate calculation
4. Customer segment analysis
5. Customer tenure and retention analysis
6. Data visualization
7. Business insights and recommendations

Dataset

The dataset will contain customer subscription information, such as tenure, contract type, monthly charges, services, and churn status.

The dataset source and details will be documented here after the dataset is selected.

Expected Deliverables

- Cleaned dataset
- Data analysis and visualizations
- Key findings and business recommendations
- Final project report
